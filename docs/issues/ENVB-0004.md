# [ENVB-0004] SSH接続のkeepalive追加で長時間処理の途中切断を防ぐ

## 背景

`scripts/core/ssh.py` の `SSHSession` は paramiko で踏み台越しに接続し、`run()` でリモートコマンドを実行する。長時間かかる処理（`make` など）を実行すると、無通信状態が続いた際に途中で接続が切断され、結果を回収できないことがある。

多段接続（踏み台経由）では、無音時間が長いと途中の TCP コネクションが切られる可能性がある。

## 目的

OpenSSH の `ServerAliveInterval` に相当する keepalive をレイヤーで有効化し、無通信中も接続を維持して長時間処理の途中切断を防ぐ。

## 対応方針（A案）

- `SSHSession.__enter__` で、踏み台を含む各 transport に `set_keepalive(30)` を設定する。
- paramiko の keepalive は SSH プロトコルの keepalive を用いるため、接続維持を SSH 側の仕組みに委ねる形になる。
- 既存の多段接続・認証・実行ロジックは変更しない（最小変更）。

## 対象外

- 出力のストリーミング化（途中経過のリアルタイム表示）
- async/poll 方式（バックグラウンド実行 + ポーリング）
- ssh バイナリへの全面移行

これらは別途検討とする。
