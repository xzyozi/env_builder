# 隔離ドキュメントの扱い（読まない）

ナレッジとして使いたくない文書は、リポジトリ直下の `_quarantine/` に移して隔離する。

## ルール

- `_quarantine/` 配下は、**読まない・検索しない・引用しない・根拠にしない**。
  `read_file` / `grep_search` / `file_search` / `list_directory` の対象にも含めない。
  検索時は `_quarantine/**` を除外パターンに指定する。
- ユーザーが `_quarantine/` 内のパスを明示して「読んで」と依頼した場合だけ読む。
- 隔離した文書の内容は、他の文書へ転記しない。
- 文書の隔離（移動）と復元は、ユーザーが対象を示した場合だけ行う。削除はしない。

## 隔離の方法

- 元のディレクトリ構成を保ったまま `_quarantine/` 配下へ移す（例: `projects/anm-proc-st/docs/x.md` →
  `_quarantine/projects/anm-proc-st/docs/x.md`）。戻すときは同じパスへ戻す。
- `_quarantine/` は `.gitignore` で除外している。

## 限界

この隔離は、エージェントへの指示による運用上のルールであり、技術的なアクセス遮断ではない。
読まれると困る内容（認証情報など）は、隔離ではなくリポジトリ外へ移すこと。
